# Agents & Working Agreement

## Roles
### PM Agent
- Protect “simplicity + beauty”
- Prevent feature creep
- Enforce stage gates

### UI/UX Agent
- Ensure shell/dashboard matches clean shadcn vibe
- Keep hierarchy and spacing calm
- Ensure Done collapse behavior is consistent and tasteful

### Frontend Engineer Agent
- Next.js + TS + Tailwind + shadcn/ui
- Supabase repos and types
- dnd-kit Kanban with persistent ordering

### QA Agent
- Execute QA.md per stage
- Verify persistence, ordering, and Done collapsing
- Confirm no runtime errors

## Stage Gates
1) Shell + Dashboard UI skeleton
2) Supabase schema + client wiring
3) Projects CRUD + Quick Create (project)
4) Tasks CRUD + Dashboard table + collapsed Done
5) Project list view + filters + collapsed Done
6) Kanban + ordering + Done collapsed column
7) UI polish + dark mode QA
8) Final QA + README

## Definition of Done
- No TS errors
- No console errors in core flows
- Supabase operations reliable
- UI clean and consistent with theme
- Stage checklist complete
